Aplikasi Pelayanan Sosial Desa

Rekomendasi Kelayakan Awal Penerima PKH

Aplikasi ini memisahkan peran pengguna: petugas hanya menginput data warga, sedangkan admin memverifikasi rekomendasi sistem dan menentukan hasil akhir.

Alur Sesuai Arahan

  • Petugas login untuk input data warga
  • Sistem menampilkan rekomendasi sistem
  • Admin login untuk melihat data masuk
  • Admin klik Verifikasi Manual/Edit
  • Admin mengisi rekomendasi manual dan keterangan
  • Sistem menampilkan hasil akhir

Rekomendasi Sistem

Hasil otomatis dari forward chaining berdasarkan input data warga, skor, DTKS, dan komponen PKH.

Rekomendasi Manual

Diisi oleh admin setelah hasil sistem muncul. Admin memilih Layak, Tidak Layak, atau Perlu Verifikasi Lanjutan.

Hasil Akhir

Keputusan akhir yang muncul dari gabungan hasil sistem, rekomendasi manual, dan keterangan admin.

Alur Penggunaan

1

Login Sesuai Peran

Petugas masuk untuk input data, admin masuk untuk verifikasi.

2

Input Data

Petugas mengisi identitas dan kondisi sosial ekonomi warga.

3

Rekomendasi Sistem

Forward chaining menghitung skor dan status sistem.

4

Verifikasi Admin

Admin mengisi keputusan manual dan keterangan.

Input Data Warga

Khusus petugas: isi data warga terlebih dahulu. Setelah disimpan, sistem menampilkan rekomendasi sistem. Verifikasi manual dilakukan oleh admin.

Komponen PKH

Komponen lansia dihitung otomatis jika umur minimal 60 tahun.

Rekomendasi Sistem Berhasil Muncul

Cari Data Warga

Khusus admin: cari berdasarkan nama, NIK, RT, rekomendasi sistem, manual, atau hasil akhir.

Hasil Pencarian

Hasil Rekomendasi

Khusus admin: setelah rekomendasi sistem muncul, klik Verifikasi Manual/Edit untuk mengisi rekomendasi manual dan keterangan.

Bobot Penilaian

Bobot digunakan untuk menghitung skor prioritas setiap warga.

Aturan Forward Chaining

Sistem membaca fakta, menambahkan bobot, lalu menentukan rekomendasi sistem.

Aturan Keputusan Sistem

Layak Diusulkan

Skor minimal 70, terdaftar DTKS, dan memiliki minimal satu komponen PKH.

Perlu Verifikasi

Skor 50 sampai 69, atau data potensial tetapi DTKS belum terdaftar.

Tidak Prioritas

Skor di bawah 50, tidak memiliki komponen PKH, atau ada indikator ekonomi kuat.

Aturan Hasil Akhir Manual

Manual Layak

Jika admin memilih Layak, hasil akhir menjadi Layak Diusulkan atau Layak Diusulkan Setelah Verifikasi Manual.

Manual Perlu Verifikasi Lanjutan

Hasil akhir menjadi Menunggu Verifikasi Lanjutan.

Manual Tidak Layak

Hasil akhir menjadi Tidak Layak Diusulkan.

Verifikasi Manual Admin

Isi bagian ini sebagai admin setelah rekomendasi sistem muncul.
