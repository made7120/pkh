Aplikasi Sistem Pakar

Rekomendasi Kelayakan Awal Penerima PKH

Aplikasi ini membantu petugas memasukkan data warga, menghitung bobot kemiskinan, menjalankan metode forward chaining, dan menghasilkan rekomendasi awal penerima Program Keluarga Harapan.

Tujuan Aplikasi

Membantu proses skrining awal calon penerima PKH berdasarkan data sosial ekonomi dan komponen PKH.

Metode

Sistem menggunakan forward chaining. Fakta dari data warga dicocokkan dengan aturan sampai menghasilkan rekomendasi.

Output

Output sistem berupa skor, komponen PKH, status rekomendasi, dan rincian bobot yang menjadi alasan keputusan.

Alur Penggunaan

1. Input Data

Admin mengisi identitas dan kondisi sosial ekonomi warga.

2. Proses Aturan

Sistem membaca fakta dan menjalankan aturan forward chaining.

3. Hitung Bobot

Setiap kriteria diberi skor sesuai tingkat prioritas.

4. Rekomendasi

Sistem menampilkan status layak, perlu verifikasi, atau tidak prioritas.

Input Data Warga

Isi data warga. Sistem akan menghitung bobot secara otomatis.

Komponen PKH

Komponen lansia dihitung otomatis jika umur minimal 60 tahun.

Bobot Penilaian

Aturan Forward Chaining

Sistem membaca fakta, menambahkan bobot, lalu menentukan rekomendasi.

Aturan Keputusan

Layak Diusulkan

Skor minimal 70, terdaftar DTKS, dan memiliki minimal satu komponen PKH.

Perlu Verifikasi

Skor 50 sampai 69, atau data potensial tetapi DTKS belum terdaftar.

Tidak Prioritas

Skor di bawah 50, tidak memiliki komponen PKH, atau ada indikator ekonomi kuat.
