Aplikasi Pelayanan Sosial Desa

Rekomendasi Kelayakan Awal Penerima PKH

Aplikasi ini membantu petugas desa memasukkan data warga, menghitung bobot prioritas, menjalankan metode forward chaining, dan menghasilkan rekomendasi awal calon penerima Program Keluarga Harapan.

Informasi Sistem

  • Metode: Forward Chaining
  • Basis: Sistem Pakar AI Simbolik
  • Output: Skor, Rekomendasi Sistem, Rekomendasi Manual, Keterangan, dan Hasil Akhir
  • Pengguna: Admin atau Petugas Desa

Tujuan Aplikasi

Membantu skrining awal calon penerima PKH secara lebih rapi, cepat, dan terarah.

Metode

Forward chaining mencocokkan fakta warga dengan aturan sampai sistem menemukan rekomendasi.

Output

Sistem menampilkan skor, komponen PKH, rekomendasi sistem, rekomendasi manual, keterangan petugas, hasil akhir, dan rincian bobot.

Alur Penggunaan

1

Input Data

Petugas mengisi identitas dan kondisi sosial ekonomi warga.

2

Proses Aturan

Sistem membaca fakta dan menjalankan aturan forward chaining.

3

Hitung Bobot

Setiap kriteria mendapat skor sesuai tingkat prioritas.

4

Hasil Akhir

Petugas memberi rekomendasi manual dan keterangan, lalu sistem menampilkan hasil akhir.

Input Data Warga

Isi data warga. Sistem akan menghitung bobot secara otomatis.

Komponen PKH

Komponen lansia dihitung otomatis jika umur minimal 60 tahun.

Rekomendasi Manual Petugas

Bagian ini diisi oleh petugas sebagai validasi lapangan setelah sistem memberikan rekomendasi otomatis.

Rekomendasi manual dan keterangan wajib diisi agar sistem dapat memunculkan hasil akhir.

Bobot Penilaian

Bobot digunakan untuk menghitung skor prioritas setiap warga.

Aturan Forward Chaining

Sistem membaca fakta, menambahkan bobot, lalu menentukan rekomendasi.

Aturan Keputusan

Layak Diusulkan

Skor minimal 70, terdaftar DTKS, dan memiliki minimal satu komponen PKH.

Perlu Verifikasi

Skor 50 sampai 69, atau data potensial tetapi DTKS belum terdaftar.

Tidak Prioritas

Skor di bawah 50, tidak memiliki komponen PKH, atau ada indikator ekonomi kuat.

Aturan Hasil Akhir

Hasil akhir ditentukan dari rekomendasi manual petugas dan keterangan verifikasi.

Manual Layak

Hasil akhir menjadi Layak Diusulkan Setelah Verifikasi Manual.

Manual Perlu Verifikasi Lanjutan

Hasil akhir menjadi Menunggu Verifikasi Lanjutan.

Manual Tidak Layak

Hasil akhir menjadi Tidak Layak Diusulkan.
