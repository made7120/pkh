Aplikasi Pelayanan Sosial Desa

Rekomendasi Kelayakan Awal Penerima PKH

Aplikasi ini membantu petugas desa memasukkan data warga, menjalankan metode forward chaining, menampilkan rekomendasi sistem, lalu menyediakan verifikasi manual petugas dengan keterangan dan hasil akhir.

Alur Sesuai Arahan

  • Petugas login terlebih dahulu
  • Input data warga
  • Sistem menampilkan rekomendasi sistem
  • Petugas klik Verifikasi Manual/Edit
  • Petugas mengisi manual dan keterangan
  • Sistem menampilkan hasil akhir

Rekomendasi Sistem

Hasil otomatis dari forward chaining berdasarkan input data warga, skor, DTKS, dan komponen PKH.

Rekomendasi Manual

Diisi setelah hasil sistem muncul. Petugas memilih Layak, Tidak Layak, atau Perlu Verifikasi Lanjutan.

Hasil Akhir

Keputusan akhir yang muncul dari gabungan hasil sistem, rekomendasi manual, dan keterangan petugas.

Alur Penggunaan

1

Login Petugas

Petugas masuk menggunakan akun yang tersedia.

2

Input Data

Petugas mengisi identitas dan kondisi sosial ekonomi warga.

3

Rekomendasi Sistem

Forward chaining menghitung skor dan status sistem.

4

Verifikasi Manual

Petugas mengisi keputusan manual dan keterangan.

Input Data Warga

Isi data warga terlebih dahulu. Setelah disimpan, sistem akan menampilkan rekomendasi sistem. Rekomendasi manual diisi setelah itu melalui tombol Verifikasi Manual/Edit.

Komponen PKH

Komponen lansia dihitung otomatis jika umur minimal 60 tahun.

Rekomendasi Sistem Berhasil Muncul

Cari Data Warga

Cari berdasarkan nama, NIK, RT, rekomendasi sistem, manual, atau hasil akhir.

Hasil Pencarian

Hasil Rekomendasi

Setelah rekomendasi sistem muncul, klik Verifikasi Manual/Edit untuk mengisi rekomendasi manual dan keterangan.

Bobot Penilaian

Bobot digunakan untuk menghitung skor prioritas setiap warga.

Aturan Forward Chaining

Sistem membaca fakta, menambahkan bobot, lalu menentukan rekomendasi sistem.

Aturan Keputusan Sistem

Layak Diusulkan

Skor minimal 70, terdaftar DTKS, dan memiliki minimal satu komponen PKH.

Perlu Verifikasi

Skor 50 sampai 69, atau data potensial tetapi DTKS belum terdaftar.

Tidak Prioritas

Skor di bawah 50, tidak memiliki komponen PKH, atau ada indikator ekonomi kuat.

Aturan Hasil Akhir Manual

Manual Layak

Hasil akhir menjadi Layak Diusulkan atau Layak Diusulkan Setelah Verifikasi Manual.

Manual Perlu Verifikasi Lanjutan

Hasil akhir menjadi Menunggu Verifikasi Lanjutan.

Manual Tidak Layak

Hasil akhir menjadi Tidak Layak Diusulkan.
